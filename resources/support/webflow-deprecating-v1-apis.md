# Webflow deprecating v1 APIs

Webflow [deprecated its v1 API](https://developers.webflow.com/data/docs/webflow-v1-api-deprecation-notice) on March 31, 2025. The v1 API may still work, but Webflow no longer maintains or supports it. All new Whalesync syncs use Webflow's v2 API, but an older sync may still be using v1.

To avoid any disruption to syncing, **reauthorize your Webflow connection in each older sync** that uses Webflow.

<figure><img src="../../.gitbook/assets/webflow reauth.png" alt=""><figcaption><p>How to reauthorize Webflow</p></figcaption></figure>

### How do I know if I need to reauthorize?

Your connection status will say "Expiring soon" (see above screenshot) if you need to reauthorize.

If not, you're good to go :white\_check\_mark:.
